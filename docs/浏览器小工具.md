# AI 可操作浏览器 - 实现计划

## Context

用户希望在桌宠应用中添加"AI可操作浏览器"功能：AI能控制浏览器执行网页操作，用户可以看到全过程。类似 Manus/Dia Browser 的体验，桌宠站在浏览器旁边帮忙查东西。

浏览器作为 ChatPanel 中的一个工具视图（类似 todolist/pomodoro/countdown），用户可以通过左上角下拉菜单切换，AI也可以自动触发。

## 核心设计

**为什么用独立 WebviewWindow 而不是 iframe：**
- iframe 有跨域限制，无法读取外部网页内容
- WebviewWindow + `eval()` 可以访问任意已加载页面的 DOM
- 用户可以看到真实的浏览器窗口

**架构：**
```
用户看到: BrowserPanel(控制面板) + BrowserWindow(真实浏览器窗口)
AI看到: 结构化页面信息 (URL/标题/链接/按钮/输入框/正文)
AI操作: 通过Pi SDK工具 → Node扩展 → stdin/stdout协议 → Rust eval() → 浏览器窗口
```

## 实现步骤

### Phase 1: Rust 浏览器核心

**新建文件：**
- `src-tauri/src/browser/mod.rs` — 模块声明
- `src-tauri/src/browser/browser_models.rs` — 数据结构（BrowserPageInfo, PageLink, PageButton, PageInput, BrowserState）
- `src-tauri/src/browser/browser_window.rs` — WebviewWindow 创建/管理/生命周期
- `src-tauri/src/browser/browser_eval.rs` — JS 注入执行（页面状态提取、点击、输入、滚动）
- `src-tauri/src/browser/browser_commands.rs` — 所有 #[tauri::command] 函数

**修改文件：**
- `src-tauri/src/lib.rs` — 添加 `mod browser;`，注册新命令到 invoke_handler

**关键实现：**
- BrowserState 管理：`Arc<Mutex<Option<BrowserSession>>>`，通过 `app.manage()` 注册
- 窗口创建：`WebviewWindowBuilder` 创建 label="browser" 的窗口，1024x768，可调整大小
- JS 注入：`eval_with_callback(js, callback)` + mpsc channel 超时等待结果
- 所有 eval JS 包裹 try-catch（Windows 上异常会被静默忽略）

**Tauri 命令列表：**
```
create_browser → 创建浏览器窗口
browser_navigate(url) → 导航到URL
browser_extract → 提取当前页面结构化信息
browser_click(selector/index) → 点击元素
browser_type(selector, text) → 输入文本
browser_scroll(direction) → 滚动页面
browser_back → 后退
close_browser → 关闭浏览器
get_browser_state → 获取当前状态
```

### Phase 2: 前端浏览器 UI

**新建文件：**
- `src/ai/browser-types.ts` — TypeScript 接口定义
- `src/ai/browser-api.ts` — invoke() 封装层
- `src/components/tools/browser-panel.tsx` — 浏览器控制面板组件

**修改文件：**
- `src/ai/chat-ui.tsx` — 添加 `'browser'` 到 ToolView，添加下拉选项和图标，添加渲染分支

**BrowserPanel 布局：**
```

└──────────────────────────────────┘
```

### Phase 3: Node 扩展（AI 工具注册）

**新建文件：**
- `src-node/extensions/browser-tools.mjs` — Pi SDK 扩展，注册浏览器工具

**修改文件：**
- `src-node/run-pi.mjs` — 在 extensionFactories 数组中添加 browser 扩展
- `src-tauri/src/ai/ai_runner.rs` — stdout 线程处理 `browser_action` 消息，写回 `browser_result`

**注册的 Pi SDK 工具：**
- `browser_navigate` — 导航到URL
- `browser_click` — 点击元素（按选择器或索引）
- `browser_type` — 输入文本
- `browser_extract` — 提取页面信息
- `browser_scroll` — 滚动页面
- `browser_back` — 后退

**stdin/stdout 协议扩展：**
```
Node→Rust: { type: "browser_action", requestId, actionId, tool, args }
Rust→Node: { type: "browser_result", actionId, result }
```

### Phase 4: 完善

- 每次操作后 emit `browser://state-changed` 事件更新前端
- 操作日志记录和显示
- 边界处理：浏览器未创建时自动创建、页面加载超时、浏览器被用户关闭
- 加载状态指示器

## 关键技术点

1. **eval_with_callback 超时**：用 mpsc channel + 10s 超时，避免永久阻塞
2. **页面导航等待**：注入 JS 检查 `document.readyState === 'complete'`，带超时
3. **元素选择**：AI 优先使用提取结果中的 index，而非原始 CSS 选择器
4. **CSP 限制**：部分网站的 CSP 可能阻止 eval()，记录为已知限制

## 验证方式

1. `npm run tauri dev` 启动应用
2. 在 ChatPanel 左上角下拉菜单选择"浏览器"
3. 在地址栏输入 URL，确认浏览器窗口打开并加载页面
4. 在聊天中说"帮我打开百度搜索xxx"，确认 AI 自动操作浏览器
5. 确认 BrowserPanel 实时显示页面状态和操作日志
