# 开发计划：Tools Runner + 小工具 UI

## 实施状态

已完成。当前实现按既定的 WebView → Rust → Node 短连接架构落地，数据按桌宠工作空间隔离存储在 `.wimipet/tools/` 下。

落地内容：
- Node 侧新增 `tools-runner.mjs`，支持 CLI 调试和 stdin JSON payload 两种模式。
- 已实现 Todolist、番茄钟、倒数日三个工具模块，并新增共享 JSON 存储 helper。
- Rust 侧新增 `tools` 模块和 `send_tools_command` Tauri command，负责启动 Node runner 并转发 `tools-event`。
- 前端新增 `Tools.*` Promise API、工具类型定义和三个工具面板。
- 聊天面板标题栏新增工具切换按钮，支持在聊天 / Todolist / 番茄钟 / 倒数日之间切换；非聊天视图隐藏聊天输入框。

与原计划的微调：
- `send_tools_command` 增加 `workspace_folder` 参数，用于明确绑定当前桌宠工作空间。
- Node 侧额外新增 `src-node/tools/storage.mjs`，避免三个工具重复读写 JSON 文件逻辑。
- Rust 模块只需要在 `src-tauri/src/lib.rs` 注册，不需要修改 `src-tauri/src/main.rs`。
- Todolist 的添加入口放在面板顶部；番茄钟和倒数日不复用聊天输入框。

验证记录：
- CLI 冒烟：Todolist add/list、Pomodoro status、Countdown add/list。
- stdin 冒烟：`todolist list` 返回单行 `done` event。
- `npm run build` 通过。
- `cargo check` 通过。
- Vite 本地页面轻量浏览器验证：工具菜单可打开，三个面板可切换，未选择桌宠时禁用态正常，控制台无 error。

## Context

用户希望为桌宠应用添加生产力小工具（番茄钟、Todolist、倒数日），采用独立进程架构（类似现有 AI Runner），支持 CLI 调试和 stdin 被 Rust 调用两种模式。UI 层在聊天输入框右上角增加工具切换按钮，点击下拉菜单切换聊天/小工具视图。

## 架构概览

```
前端 TS ──invoke()──▸ Rust ──spawn node──▸ tools-runner.mjs
   ◂──event()──────── ◂──emit("tools-event")── stdout JSON lines ─┘
```

与 AI Runner 完全一致的通信模式：短连接、stdin 输入、stdout JSON lines 输出。

## 第一阶段：Tools Runner（Node 进程）

### 1.1 创建入口文件 `src-node/tools-runner.mjs`

**核心设计：双模式入口**
- CLI 模式：`process.argv.length > 2` 时解析命令行参数，结果输出美化 JSON 到 stdout
- stdin 模式：读取 stdin JSON payload，结果输出单行 JSON event 到 stdout

**命令协议：**
```
输入: { requestId, command, action, params }
输出: { type: "done", requestId, data } 或 { type: "error", requestId, error }
```

**数据目录：** 通过环境变量 `TOOLS_DATA_DIR` 传入，默认 `process.cwd()/.wimipet/tools`

### 1.2 实现三个工具模块

**`src-node/tools/todolist.mjs`** — Todolist 管理
- `list` — 列出所有 todo（支持 `--status pending|done|all` 筛选）
- `add` — 添加 todo（`--text`, 可选 `--dueDate`）
- `complete` — 标记完成（`--id`）
- `uncomplete` — 取消完成（`--id`）
- `delete` — 删除（`--id`）
- `update` — 更新文本或日期（`--id`, `--text`, `--dueDate`）

存储文件：`todolist.json`
```json
{
  "todos": [
    {
      "id": "todo-xxx",
      "text": "买菜",
      "completed": false,
      "createdAt": 1716806400,
      "completedAt": null,
      "dueDate": "2026-05-28"
    }
  ]
}
```

**`src-node/tools/pomodoro.mjs`** — 番茄钟
- `start` — 开始专注（`--duration` 默认 25，可选 `--label` 标签如"写代码"）
- `pause` — 暂停
- `resume` — 恢复
- `stop` — 停止（提前结束）
- `status` — 查询当前状态（剩余秒数、是否运行中、今日完成数）
- `history` — 今日历史记录

存储文件：`pomodoro.json`
```json
{
  "current": {
    "id": "pomo-xxx",
    "label": "写代码",
    "durationMinutes": 25,
    "startedAt": 1716806400,
    "pausedAt": null,
    "totalPausedSeconds": 0,
    "status": "running"
  },
  "todayCompleted": [
    {
      "id": "pomo-yyy",
      "label": "写文档",
      "durationMinutes": 25,
      "startedAt": 1716800000,
      "endedAt": 1716801500,
      "status": "completed"
    }
  ],
  "todayDate": "2026-05-27"
}
```

**`src-node/tools/countdown.mjs`** — 倒数日
- `list` — 列出所有倒数日
- `add` — 添加（`--name`, `--date` 格式 YYYY-MM-DD，可选 `--repeat yearly`）
- `update` — 更新（`--id`, `--name`, `--date`）
- `delete` — 删除（`--id`）

存储文件：`countdown.json`
```json
{
  "events": [
    {
      "id": "cd-xxx",
      "name": "生日",
      "date": "2026-08-15",
      "repeat": "yearly",
      "createdAt": 1716806400
    }
  ]
}
```

### 1.3 CLI 验证

```bash
# Todolist
node src-node/tools-runner.mjs todolist add --text "买菜"
node src-node/tools-runner.mjs todolist list
node src-node/tools-runner.mjs todolist complete --id todo-xxx

# 番茄钟
node src-node/tools-runner.mjs pomodoro start --duration 25 --label "写代码"
node src-node/tools-runner.mjs pomodoro status

# 倒数日
node src-node/tools-runner.mjs countdown add --name "生日" --date "2026-08-15"
node src-node/tools-runner.mjs countdown list
```

## 第二阶段：Rust 侧集成

### 2.1 创建 `src-tauri/src/tools/` 模块

仿照 `src-tauri/src/ai/` 结构：

- `mod.rs` — 模块声明 + re-export
- `tools_models.rs` — 数据结构定义（`TodoItem`、`PomodoroState`、`CountdownEvent`）
- `tools_commands.rs` — `#[tauri::command]` 函数
- `tools_runner.rs` — Node 子进程启动 + stdout 读取 + event emit

### 2.2 Tauri Commands

```rust
#[tauri::command]
fn send_tools_command(
    app: AppHandle,
    workspace_folder: String,
    request_id: String,
    command: String,      // "todolist" | "pomodoro" | "countdown"
    action: String,       // "list" | "add" | "complete" | ...
    params: Value,        // JSON 对象
) -> Result<(), String>
```

### 2.3 进程启动逻辑 `tools_runner.rs`

- 读取 `TOOLS_DATA_DIR` 环境变量（从 app data dir 拼接）
- `Command::new("node").arg("src-node/tools-runner.mjs")` spawn 进程
- stdin 写入 JSON payload
- stdout 逐行读取 JSON，`app.emit("tools-event", event)` 转发到前端
- 进程退出后清理

### 2.4 注册 Command

在 `src-tauri/src/lib.rs` 中注册 `send_tools_command`。

### 4.3 状态管理

在 `ChatUI` 组件内新增 state：

```typescript
type ToolView = 'chat' | 'todolist' | 'pomodoro' | 'countdown';
const [activeView, setActiveView] = useState<ToolView>('chat');
```

### 4.4 面板切换逻辑

`Conversation` 区域（第 416-460 行）根据 `activeView` 条件渲染：

- `'chat'` — 渲染现有对话内容

`PromptInput` 区域也根据 `activeView` 切换：
- `'chat'` — 现有聊天输入框

### 4.5 工具面板组件

创建 `src/components/tools/` 目录：

### 4.6 输入框适配

## 关键注意事项

1. **TOOLS_DATA_DIR** — Rust 侧从 `app.path().app_data_dir()` 拼接，传给 Node 进程的环境变量
2. **番茄钟计时** — Node 进程是短连接，计时逻辑基于 `startedAt` + `durationMinutes` 计算剩余时间，不依赖进程常驻
3. **UI 复用** — 工具面板复用现有 shadcn/ui 组件（Button、Card、Checkbox、Input、Badge）
4. **compact 模式兼容** — 宠物窗口气泡也需要支持工具切换，面板需要响应式适配小尺寸
