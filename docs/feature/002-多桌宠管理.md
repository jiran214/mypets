1. 你的目标用户是中文群体，ui要为他们考虑

2. 着陆页改成多桌宠管理（只能同时启动一只），一打开可以看到已添加的桌宠列表，以及一个"创建"按钮，文件夹导入后会变成该agent的工作空间

3. 点击桌宠列表的某个桌宠即进入该工作空间、
非tab区域包括工作空间的信息提示、开始按钮
4. 三个tab，皮肤、设置、聊天
- 皮肤：会读取该文件夹下的皮肤资源，提供预览，可以点击上传皮肤文件夹，必须包含所需的webp和json
- 设置：
  - 需要这些信息：Claude CLI路径（文本框）、加载用户Claude设置（使用Toggle Switch，总是会读取该工作空间下的claude设置，开启后读取~/.claude/setting.json）、权限模式、自定义环境变量（多行文本框）
- 聊天：
  - 取消消息旁边发送者名称
  - AI的输出不应该只是纯文本，渲染AI不同格式的输出，比如思考、规划、工具调用、mcp调用、skill使用，文件路径
5. 气泡聊天窗口，应该放置在桌宠的正上方，右上角有叉号关闭
6. 信息存储：从默认的AppData改为当前工作空间 
7. 美观好看，整体设计风格偏向卡通
