# Wimi Pet 代码优化总结

本次优化覆盖项目全部源文件，按 7 个阶段逐一完成。以下为各阶段改动概要。

---

## Phase 1: 安全加固 — Rust 路径校验

**目标：** 对所有接受文件路径的 Tauri 命令增加目录白名单校验，防止路径穿越。

- `src-tauri/src/pet.rs`：新增 `validate_pet_folder`，对 `load_pet`、`load_spritesheet`、`delete_pet_workspace`、`open_workspace_in_file_manager` 增加 canonicalize + home 目录校验
- `src-tauri/src/ai.rs`：新增 `validate_workspace_path`，对 `storage_paths` 增加 canonicalize + home 目录校验，覆盖全部 8 个调用点

---

## Phase 2: 进程管理与稳定性

**目标：** 修复线程泄漏、增加超时、修复中断机制。

- `src-tauri/src/ai.rs`：child.wait() 改为 30 秒超时轮询；保存 JoinHandle 检测 panic；SIGKILL 兜底；非 JSON stdout 记录日志；stderr 缓冲 64KB 上限
- `src-node/claude-runner.mjs`：runClaude 使用 AbortController 传 signal；runCodex 设置 kill handler
- `src/auto-tasks.ts`：runAutoTaskConversation 增加 30 分钟超时

---

## Phase 3: 内存、性能与行为修复

**目标：** 修复内存泄漏、增加防抖、添加 stop() 方法。

- `src/chat-runtime.ts`：saveCurrentConversation 改为 500ms 防抖，新增 flush() 方法
- `src/components/ai-elements/code-block.tsx`：highlighterCache LRU 上限 20，tokensCache 上限 200
- `src/renderer.ts`：SpriteRenderer 新增 stop() 和 dispose() 方法
- `src-tauri/src/ai.rs`：append_ai_log 改用 BufWriter 保持文件句柄

---

## Phase 4: 提取共享 TypeScript 工具函数

**目标：** 消除前端代码重复。

- 新建 `src/lib/tauri-utils.ts`：hasTauriRuntime、safeCurrentWindow、useTauriListen hook
- 新建 `src/lib/ai-utils.ts`：parseToolQuestionPartData、isToolQuestionStatus、appendPart、persistConversation
- 修改 `src/ai-api.ts`、`src/chat-ui.tsx`、`src/interaction.ts`、`src/chat-runtime.ts`、`src/auto-tasks.ts`、`src/manager-app.tsx` 使用共享函数

---

## Phase 5: Rust 代码去重

**目标：** 消除 ai.rs 内部的代码重复。

- 合并 AiSessionMeta/AiSessionSummary 为单一结构体
- 提取 `collect_skill_names` 消除 skill 扫描重复
- 提取 `resolve_storage` 合并 storage_paths + ensure_storage
- 15 个 default_* 函数用 `default_fn!` 宏生成

---
