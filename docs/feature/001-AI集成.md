## 新需求：AI 桌宠 Chatbot + 多 Tab 设置页

在现有 mypets Tauri 桌宠应用基础上，新增 AI Chatbot 功能，并重构现有着陆页为多 Tab 管理界面。当前项目已有 Tauri 2、TypeScript/Vite、Canvas 2D 桌宠渲染、透明置顶宠物模式、右键菜单、宠物文件夹加载和本地持久化能力。

### 一、页面结构调整

将现有“着陆页”改造成多 Tab 页面：

1. **皮肤 Tab**

   * 复用现有着陆页功能。
   * 继续支持选择宠物文件夹、预览宠物、开始进入桌宠模式。
   * 本质上是把当前页面重命名/迁移为“皮肤”。

2. **设置 Tab**

   * 用于 AI 相关配置。
   * 第一版配置方案完全参考 Claudian：

     * provider 配置；
     * Claude CLI / SDK 路径配置；
     * provider-specific settings；
     * 会话与权限相关配置入口。
   * Claudian 的架构中，`app` 层负责共享设置与插件级存储，`features/settings` 提供设置页，并包含 provider-owned Claude/Codex tab renderers，可作为参考。([GitHub][1])

3. **聊天 Tab**

   * 与桌宠交互时弹出的聊天窗口复用同一套 Chat UI 和 Chat Runtime。
   * 聊天 Tab 是完整页面形态。
   * 桌宠气泡是浮动迷你形态。
   * 二者共享：

     * 消息列表；
     * 输入框；
     * 流式输出；
     * 会话状态；
     * 错误处理；
     * provider runtime。

### 二、桌宠交互聊天

用户点击桌宠后，显示一个**跟随桌宠的聊天气泡窗口**。

要求：

* 气泡位置跟随桌宠窗口附近显示。
* 点击桌宠打开/关闭聊天气泡。
* 聊天气泡与“聊天 Tab”复用代码。
* 气泡应轻量，不替代主设置页。
* 不改变现有右键菜单逻辑。
* 本次开发不涉及桌宠动作动画联动，不需要根据 AI 状态切换 `waiting`、`review`、`failed` 等动画。

### 三、AI 功能方案

第一版 AI 功能完全参考 Obsidian Claudian 的技术方案。

Claudian 是一个将 Claude Code、Codex、Opencode 等 AI coding agents 嵌入 Obsidian 的插件，支持聊天、文件读写、搜索、bash、多步骤工作流、多 Tab 会话、历史、resume、fork 等能力。([GitHub][2])

本项目第一版只接入 **Claude Agent SDK / Claude provider**。

实现建议：

* 新增 provider-neutral chat runtime 抽象。
* 第一版只实现 Claude provider。
* 保留未来接入 Codex / OpenAI / 本地模型的扩展点。
* Conversation 模型参考 Claudian：

  * `providerId`
  * `providerState`
  * provider 自己维护 opaque state。
* Claudian 明确使用 `Conversation.providerId` 加 provider-owned `providerState` 统一多 provider 会话模型。([GitHub][1])

Claude Agent SDK 使用官方 TypeScript 包 `@anthropic-ai/claude-agent-sdk`，该 SDK 用于以编程方式构建具备 Claude Code 能力的 agent。([GitHub][3])

### 四、存储方案

第一版存储方案完全参考 Claudian。

建议在 mypets 的应用数据目录下建立类似结构，例如：

```text
.mypets-ai/
  settings.json
  sessions/
    *.meta.json

.claude/
  settings.json
  mcp.json
  commands/
  skills/
  agents/

~/.claude/projects/
  *.jsonl
```

对应关系：

* `.claude/settings.json`：Claude Code-compatible 项目设置、权限、插件覆盖配置。
* `.mypets-ai/settings.json`：mypets 自己的共享设置与 provider-specific 配置。
* `.mypets-ai/sessions/*.meta.json`：provider-neutral 会话元数据。
* `~/.claude/projects/.../*.jsonl`：Claude 原生 transcript。
* `.claude/mcp.json`、`.claude/commands`、`.claude/skills`、`.claude/agents`：保留 Claudian 同款扩展能力入口。

Claudian 的官方项目文档中列出的存储方案正是 `.claudian/claudian-settings.json`、`.claudian/sessions/*.meta.json`、`.claude/settings.json`、`.claude/mcp.json`、`.claude/commands`、`.claude/skills`、`.claude/agents`、`~/.claude/projects/{vault}/*.jsonl` 等路径。([GitHub][4])

### 五、范围边界

本次开发包含：

* 着陆页改多 Tab。
* 现有页面迁移为“皮肤 Tab”。
* 新增“设置 Tab”。
* 新增“聊天 Tab”。
* 点击桌宠弹出跟随式聊天气泡。
* 聊天气泡与聊天 Tab 复用 UI/状态/runtime。
* 接入 Claude Agent SDK。
* AI 功能与存储模型参考 Claudian。

本次开发不包含：

* 桌宠动作动画联动。
* 新增宠物动画状态。
* 根据 AI 回复切换桌宠动作。
* Codex / OpenAI / Opencode 多 provider 实现。
* MCP、Skills、Slash Commands 的完整 UI 实现；只保留架构和存储扩展点。

### 六、验收标准

* 启动后可进入新的多 Tab 管理页。
* “皮肤”Tab 保持现有宠物选择、预览、开始功能。
* “设置”Tab 可配置 AI provider / Claude 相关参数。
* “聊天”Tab 可与 AI 对话。
* 进入桌宠模式后，点击桌宠出现跟随式聊天气泡。
* 气泡聊天与聊天 Tab 共享同一个会话。
* AI 回复支持流式输出。
* 会话元数据、本地配置、Claude transcript 存储方式参考 Claudian。
* 现有桌宠拖拽、右键菜单、透明置顶、设置返回功能不被破坏。

剩下唯一需要你决定的是：`.claude/` 和 `.mypets-ai/` 放在用户 AppData 目录，还是放在当前项目/宠物工作目录下。
